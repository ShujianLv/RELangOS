为代理与协同而生的操作系统

RELang OS 把 Erlang 验证过的进程模型，做成系统的第一性原则。 应用跑在 RVM 上 — Rust 实现的 BEAM 虚拟机，之于 RELang，如同 ART 之于 Android。

原理

操作系统该如何对待失败、权限与智能

多数移动栈按「人点 App」设计：粗粒度权限、单机 IPC、全局式服务进程。 当设备开始替你调用工具、跨端完成一件事、在野外自我恢复时，这些假设会先碎裂。

RELang 的起点不是再做一个兼容层，而是换一套原语： 一切皆进程，一切皆消息；错误靠监督树结构化恢复； 能做的事只能来自被授予的能力句柄 — 没有环境权限。

  1. 01

    任其崩溃，结构化恢复

    服务挂了，先重启子树，而不是拖垮整机用户态。热升级面向组件，而不是「下次进站再刷」。

  2. 02

    没有环境权限

    不能因为「知道名字」就拿到相机或电台。能力可衰减、可过期、可审计 — 代理与应用同一套闸。

  3. 03

    位置透明

    本机 Actor 与另一台设备上的 Actor，使用同一套消息语义。多设备不是账号同步的附属品，而是运行时能力。

  4. 04

    诚实失败

    设备不在、宿主未挂，返回 unavailable — 不编造邻居、不假装起飞、不假冒推理成功。

架构

一层运行时，贯通应用、服务与代理

开发者面对的是统一的 RVM 与能力模型。换设备时换的是 HAL 与产品 Profile，不是另一套应用运行时。 UI 状态留在进程里，像素路径在 Rust 原生层 — 避免把帧钟绑在全局 GC 上。 

┌─────────────────────────────────────────┐
│  Gleam / Elixir / Erlang 应用与代理      │
│  消息 · Intent · 工具 schema · 能力租约  │
├─────────────────────────────────────────┤
│  系统监督树  framework                   │
│  连接 · 媒体 · UI 壳 · AI · 现场任务     │
├─────────────────────────────────────────┤
│  RVM — Rust BEAM 虚拟机                  │
│  解释 / JIT / AOT · Seed · Dist · Dirty  │
├─────────────────────────────────────────┤
│  原生层  合成器 · UI 引擎 · HAL · 加速器 │
├─────────────────────────────────────────┤
│  Linux（前期）  隔离 · 异步 I/O · 调度   │
└─────────────────────────────────────────┘

RVM 承载 BEAM 语义：轻量进程、邮箱、链接与监视、每进程堆。 长阻塞与推理进 Dirty 线程，不堵调度器。

Domain 划分信任：System 握策略与桥；App 握作业；Agent 只能经工具与能力行动； 厂商 SDK 与不可信原生进 Isolated。

内核前期复用主线 Linux 与厂商 BSP — 创新集中在运行时与框架，而不是再造驱动宇宙。

价值

它解决谁的什么问题

给产品与交付

垂直设备可以卖「永不整机重启、可审计的代理作业、多终端一体」— 不必先赢下消费应用商店。

给系统集成

能力与 Domain 把权限、崩溃域、原生桥的边界写死。缺硬件时诚实失败，联调不靠假成功。

给现场与机队

任务软件可热升级；子模块故障可恢复；编队与地面站走同一 mesh 叙事，而不是临时拼 MQTT 脚本。

窗口期在架构，不在功能清单

端侧模型、NPU、MCP / A2A、开源 GPU 驱动与内存安全语言同时就绪。 现有 OS 仍以 App 为粗粒度单位；RELang 以进程、能力与代理为粒度 — 这是结构性窗口，而不是多几个设置页。

特性

系统一等公民，而不是外挂

AI 代理原生

代理是被监督的进程，不是悬浮聊天窗。工具调用走能力、确认与配额； 审计落在消息路径上。外部编程助手可通过 MCP / LSP 适配接入 Host — 产品不自研 Codex，但把系统做成「好用的后端」。

Agent · Tool · Quota · Audit · MCP

多设备即一台机器

发现、配对、会话与分区有明确状态；传输未就绪就不假装连通。 迁移与跨设备授权要求更高信任等级。个人集群与现场编队共用同一套语义。

Mesh · Session · Capability · Migration

端侧加速器统一面

CPU、GPU、NPU、TPU 是同一加速器类的后端，不是四套产品 API。 应用看见任务与模型 ID；大张量走句柄。推理在隔离域运行，与 UI 绘制队列隔离，避免拖死帧钟。

AcceleratorClass · Buffer · Isolated · Dirty

声明式 UI，原生渲染

状态与业务在 BEAM 进程；布局、文本与合成在 Rust。 目标是跨手机、平板、车机、手持终端可控的像素路径 — 不依赖厂商 Widget 库冷启动生态。

Gleam UI · Compositor · 120Hz 预算

可测与可回放

时间、随机与输入可注入。会话与操作可录制回放，便于代理行为审计与现场事故追溯 — 这对工业与机队，比对消费者桌面更刚需。

Deterministic · Replay · Audit trail

垂直 · FieldCompanion

无人机与机器人：做任务 OS，不当飞控

现场伴飞 / 伴控是同一垂直 Profile。RELang 负责作业编排、感知闭环、围栏与安全意图、多机协同与 OTA； 姿态环、伺服周期与安全 PLC 留在 PX4、ArduPilot、运动控制器或厂商栈。经 MAVLink / ROS 2 等桥对接 — framework 不直接 ioctl。

无人机伴飞

机载任务电脑跑巡检流程、视觉检测、禁飞协调与地面站联动；飞控仍掌握最终执行权。失联返航由飞控裁决，RELang 不冒充「已起飞」。

合适：工业巡检、物流末端、多机协同 · 不合适：取代飞控固件

机器人与工业边缘

工控机 / 智能盒上的工艺 Actor、视觉引导、换型与人机协同；AGV 与产线屏进同一集群。运动控制与 SIL 安全回路仍在专用栈。

合适：AMR、巡检、臂旁智能盒 · 不合适：EtherCAT 内环、安全 PLC 替代
