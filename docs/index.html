RELang OS

面向 AI 代理与多设备协同的操作系统 · RVM 运行时 · 能力安全 · 监督树与热升级

Public site · Source in private repo

定位

应用运行在 RVM（Rust 实现的 BEAM 虚拟机）上。 系统服务采用 Erlang/OTP 式监督树；UI 与 HAL 以 Rust 为主路径。

类比

AndroidRELang OS
ARTRVM
Binder消息 + 域间通道
Manifest 权限能力（Capability）

差异化

  • AI 代理原生 — 工具调用、配额、审计与 MCP 适配
  • 多设备即一台机器 — 集群会话与能力边界
  • 永不重启 — 子树恢复与组件热升级
  • 垂直设备 — 工业、AI 硬件、无人机伴飞、机器人边缘任务

现场伴飞 / 伴控（FieldCompanion）

机载与边缘侧重 任务与协同：作业编排、感知推理、多机 mesh、OTA。 飞控与伺服硬实时留在外部栈，经 MAVLink / ROS 2 等桥接，不内嵌进 RVM 内环。
